# github-projeto

## Padrão de Commits

Este projeto utiliza o padrão **Conventional Commits**.  
Consulte o [CONTRIBUTING.md](./CONTRIBUTING.md) para detalhes.

### Guia rápido
| Tipo      | Uso recomendado              | Exemplo                                      |
|-----------|------------------------------|----------------------------------------------|
| feat      | Nova funcionalidade          | `feat(auth): adicionar login com Google`     |
| fix       | Correção de bug              | `fix(api): corrigir erro de timeout`         |
| docs      | Alterações na documentação   | `docs(readme): atualizar instruções`         |
| style     | Formatação sem impacto       | `style(ui): padronizar indentação`           |
| refactor  | Refatoração sem mudar lógica | `refactor(core): simplificar autenticação`   |
| test      | Inclusão/ajuste de testes    | `test(user): incluir testes de integração`   |
| chore     | Manutenção/configurações     | `chore(deps): atualizar dependências`        |
